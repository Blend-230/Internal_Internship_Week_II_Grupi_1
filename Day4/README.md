Day 4 - API Explorer App

This Flutter app reads data from a public API and displays it in a list.

What works:
- HTTP GET request
- async/await and Future
- JSON parsing with jsonDecode
- Post model class
- ApiService class
- Loading indicator
- Error message
- Success state with ListView
- Refresh button

API used:
https://jsonplaceholder.typicode.com/posts

What can be added later:
- HTTP POST
- Search/filter
- Cloudflare D1 backend
- Hosting with Cloudflare Pages or Replit
