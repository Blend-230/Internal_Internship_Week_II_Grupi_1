# Task Tracker App

Day 3 - Task 2 Flutter project for the Internal Internship.

## What it includes

- `TaskItem` model class for each tracked item.
- Add new task through a dialog form.
- Mark tasks as done or active with a checkbox.
- Delete tasks from the list.
- Total, active, and done counters.
- SnackBar feedback for add, status change, and delete actions.
- Responsive layout for mobile and desktop widths.

## What can be added later

- Edit existing tasks.
- Filter by all, active, and done.
- Save tasks locally.
- Screenshot after running the app locally.

## Run

```bash
flutter pub get
flutter run
```
