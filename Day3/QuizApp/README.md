# Quiz App

A responsive multi-screen Flutter quiz created for Internal Internship Day 3.

## Features

- 5 quiz questions with 4 answer options each
- State for the current question and score
- Progress indicator and score preview
- Result screen opened with `Navigator`
- Restart button that resets the quiz
- Responsive layout for mobile and desktop screens
- Material 3 theme

## Run locally

```bash
flutter pub get
flutter run
```

## Test

```bash
flutter test
```
