# Quiz App

Day 3 - Task 1 Flutter project for the Internal Internship.

## What it includes

- Multi-screen quiz with 5 questions and 4 options for each question.
- `setState` for current question and score updates.
- Final result screen opened with `Navigator.pushReplacement`.
- Restart button that starts the quiz again from the first question.
- Short feedback with `SnackBar` after each answer.
- Responsive layout for mobile and desktop widths.

## What can be added later

- More questions and categories.
- Timer for each question.
- Saved high score.
- Screenshot after running the app locally.

```bash
flutter pub get
flutter run
```
