Day 3 - Mini Quiz App

This Flutter app demonstrates state management and navigation.

What works:
- Model class for quiz questions
- Dynamic list of questions
- setState to update the UI
- Navigator.push to open the result screen
- Navigator.pop to restart the quiz
- SnackBar feedback for answers
- AlertDialog for question details

What can be added later:
- More quiz questions
- Categories
- Timer
- Better score design
