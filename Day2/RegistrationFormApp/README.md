# Registration Form App

A responsive Flutter registration form created for Internal Internship Day 2.

## Features

- Full name, email, password, role, and status inputs
- Email format validation and minimum password length validation
- Inline error messages that keep the layout stable
- Success dialog with a registration summary
- Responsive form layout for mobile and desktop screens
- Material 3 theme

## Run locally

```bash
flutter pub get
flutter run
```

## Test

```bash
flutter test
```
