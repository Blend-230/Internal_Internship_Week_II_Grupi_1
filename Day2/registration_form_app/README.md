# Registration Form App

Day 2 - Task 2 Flutter project for the Internal Internship.

## What it includes

- Registration form with name, email, password, role, and status fields.
- Email validation and minimum password length validation.
- Inline error messages that keep the form layout stable.
- Password visibility toggle and active/inactive status switch.
- Success dialog with a registration summary.
- Responsive card width for mobile and desktop screens.

## Run

```bash
flutter pub get
flutter run
```
