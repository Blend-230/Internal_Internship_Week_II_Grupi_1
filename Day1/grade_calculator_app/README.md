# Grade Calculator App

Day 1 - Task 2 Flutter project for the Internal Internship.

## What it includes

- Three TextField inputs for numeric grades or points.
- Validation for empty fields and invalid numbers.
- Average result formatted with two decimal places.
- Status result: Kalon or Duhet permiresim.
- Responsive card layout for mobile and desktop width.

## Run

```bash
flutter pub get
flutter run
```
