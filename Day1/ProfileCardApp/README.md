# Profile Card App

A responsive Flutter profile card created for Internal Internship Day 1.

## Features

- Profile name, professional role, description, and avatar icon
- Contact information displayed with reusable widgets
- Responsive layout for mobile and desktop screens
- Button that displays a `SnackBar`
- Material 3 theme

## Run locally

```bash
flutter pub get
flutter run
```

## Test

```bash
flutter test
```
