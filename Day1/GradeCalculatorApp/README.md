# Grade Calculator App

A responsive Flutter application created for Internal Internship Day 1, Task 2.

## Features

- Accepts three numeric grades or scores
- Validates empty fields and non-numeric values
- Displays the calculated average with two decimal places
- Shows `Kalon` when the average is at least 50
- Shows `Duhet permiresim` when the average is below 50
- Responsive layout for mobile and desktop screens

## Run locally

```bash
flutter pub get
flutter run
```

## Test

```bash
flutter test
```
